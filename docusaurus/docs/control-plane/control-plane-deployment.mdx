# Deploy APIM Control Plane with Kubernetes Gateway

There are 3 components that you need to deploy to get the Kubernetes Gateway working with APIM. They are:

- [WSO2 API Manager 4.5.0](../control-plane/apim-deploy.mdx)
- [WSO2 Kubernetes Gateway 1.3.0](../control-plane/apk-deploy.mdx)
- [WSO2 Kubernetes Gateway Agent 1.3.0](../control-plane/apim-apk-agent-deploy.mdx)
