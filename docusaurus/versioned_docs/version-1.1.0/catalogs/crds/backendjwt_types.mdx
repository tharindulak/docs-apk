## BackendJWT Sample

The following is a sample `BackendJWT` CR.

```
apiVersion: dp.wso2.com/v1alpha1
kind: BackendJWT
metadata:
  name: backendjwt
spec:
  encoding: "base64"
  signingAlgorithm: "SHA256withRSA"
  header: "X-JWT-Assertion"
  tokenTTL: 3600
  customClaims:
    - claim: "admin"
      value: "http://wso2.org/claims/enduser"
    - claim: "test"
      value: "1"
      type: float
```

Refer [Learn to attach API Policies for Backend JWT Token Manipulation](../../create-api/create-and-attach-api-policies/backend-jwt-token-manipulation/backend-jwt-token-manipulation-via-crs.mdx) for more information on how to configure backend JWT in APK.
