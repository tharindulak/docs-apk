## Scope Sample

The following is a sample Scope CR. Scopes are used to define the access level of an API resources.

```
apiVersion: "dp.wso2.com/v1alpha1"
kind: "Scope"
metadata:
  name: api-scope
spec:
  names:
    - "org"

```
